# 鹅厂调研：大厂在Agent模型及Coding领域追赶MiniMax及Kimi潜在时间窗口，模型蒸馏技术及人才对模型追赶的具体影响，OpenClaw对模型厂商及云厂商的带动差异 – MiniMax/Kimi/智谱/阿里/字节

1，如何看待当前国内AI模型市场的竞争格局？大型科技公司在模型能力上面临哪些挑战，以及未来的关键时间节点是什么？

当前国内市场的竞争焦点仍在模型能力上。一个显著的趋势是，新兴创业公司（小厂）在模型能力上暂时领先于大型科技公司（大厂）。尽管大厂看似凭借开源模型迅速入局（OpenClaw），但以Kimi和MiniMax为代表的小厂在特定模型领域表现更优。

一个关键的变量是小厂未来的闭源策略（专家判断Kimi、MiniMax等后续会逐渐走向闭源）。参照北美市场，优质的开源模型已趋于边缘化，主流厂商均已闭源。因此，国内的MiniMax和Kimi等厂商在下一版本中很大概率会选择闭源。一旦它们闭源，而届时大厂又未能推出性能相当的模型，那么在“短期看模型”的竞争准则下，大量用户可能会从大厂的AI平台迁移至小厂的平台，帮助小厂构筑用户认知和入口壁垒。

这对大厂构成了一个紧迫的时间窗口，预计在2026年9月前，大厂需要推出一款能够在通用智能体领域追赶上小厂的模型。目前，大厂与小厂的模型发展路径已出现分化。小厂，包括DeepSeek、Kimi、MiniMax和智谱AI，自2024年起战略方向明确为打造“中国版Anthropic”，专注于算力消耗相对较少且能形成长期飞轮效应的通用智能体及Coding模型。相比之下，大厂在2024至2026年间的发展重点是为了支持其AI Bot业务，主要研发通用搜索、通用知识问答、强逻辑写作等通用AGI能力的模型，例如字节的豆包2.0、阿里的千问3.5 Plus以及腾讯的混元2.0。

2026年，大厂已意识到这一危机并开始进行技术转向，发力通用智能体和Coding领域。能否在小厂闭源前追赶上其模型能力，将直接影响大厂能否发挥出自身中期的产品优势。

2，从海外市场的经验来看，追赶领先的通用智能体和Coding模型有多大难度？国内大型科技公司在人才方面面临怎样的局面？

追赶过程存在显著挑战。以海外市场为例，OpenAI从GPT-5.0版本开始尝试追赶Anthropic在通用智能体和Coding模型上的能力。这一追赶始于2025年1月，当时双方在token消耗量上各占市场约25%的份额。但从2025年2月Anthropic反超后，OpenAI便再未追上。OpenAI历经GPT-5.0、5.1、5.2、5.3，直到本月（2026年3月）初发布的5.4版本，才大体上追平了Anthropic的模型能力。这个过程耗费了四个大版本迭代和将近一年半的时间。

考虑到国内小厂可能在2026年9月闭源，留给大厂只有约半年的追赶时间，形势非常严峻。模型能力的竞争本质上是人才的竞争，而目前国内在通用智能体及Coding领域做得好的人才大多集中在小厂。大型科技公司在这方面则面临一些困境：阿里千问3.0的Coding负责人已经离职，新招募的周浩来自Gemini 3.0团队，但Gemini 3.0的强项在于通用基座和多模态，而非Coding，因此阿里下一版本模型的多模态和通用能力可能会增强，但Coding能力提升有限；字节跳动原本就缺乏Coding领域的顶尖人才；腾讯之所以能力有望提升，是因为成功从DeepSeek和Kimi挖到了相关人才。因此，整体来看，大厂追赶的压力非常紧迫。

3，Anthropic曾指责国内厂商蒸馏其模型，那么对于想在智能体和Coding领域快速提升能力的大厂而言，通过蒸馏的方法追赶是否可行？

通过蒸馏来追赶是可行的。如果Anthropic有办法，就不会仅仅在社交媒体上发帖抨击。当无法通过技术或法律手段解决时，才会诉诸舆论。

模型间的互相蒸馏在全球范围内是普遍现象，并非存在道德污点。厂商们通常会选择性地蒸馏全球前沿模型中最强的部分，例如，A模型的数学能力强，就蒸馏其数学；B模型的科研能力突出，就蒸馏其科研；Anthropic的代码能力好，就蒸馏其代码。海外厂商之间、以及海内外厂商之间都存在互相蒸馏的行为，目的是在各项模型评分中，将自身最强的能力点进一步拔高。

虽然“蒸馏”听起来像是简单的“抄作业”，但它本身是一项非常细分和复杂的技术。蒸馏本质上只能迁移一部分模型能力，而无法解决根本性的问题。具体来说，许多核心能力无法通过蒸馏获得。例如，海外Claude模型支持100万上下文长度，而国内主流模型仅为256K，这种上下文能力是蒸不来的。同样，海外模型的原生多模态能力、低于1%的幻觉率（国内普遍在3%-5%），以及在长上下文中的“大海捞针”等能力，都无法通过蒸馏复制。

蒸馏能够解决的，主要是核心思维路径（如优质的思维链标注数据）和答题偏好性等问题。当一个模型的回答风格和偏好更受用户欢迎时，其他模型可以通过蒸馏快速模仿，以提升用户体验。总体而言，蒸馏大概只能解决整体问题的20%至25%，甚至更少。绝大部分问题的解决，依然依赖于厂商自身的技术积累，而这主要通过两个途径实现：一是挖人，二是投入足够的算力。

4，在当前AI人才流动频繁、各大厂商算力储备相对充足的背景下，决定模型能力追赶速度的核心因素是什么？

核心因素是人。从2023年至今的所有案例都印证了“人去哪儿，谁的能力就强”这一规律。因此，观察人员流动即可判断各家能力的走向。

人员流动背后反映的是企业高层的战略决心。只有当高层在战略上决定大力投入时，才愿意支付数亿元的薪资去挖顶尖人才。一旦投入巨资将人才招致麾下，企业必然会为其配备充足的底层资源，包括算力。因为如果因资源不足导致项目失败，那么之前的人才投入就失去了意义。所以，看到人员的流动，就基本可以判断出高层对该方向的战略目标和意志。归根结底，看人就够了。

 

5，如何评价Meta在AI团队组织架构上的调整及其对其他厂商的启示？

Meta是组织架构调整的负面教材。其一，新负责人本身是数据方向出身，在大模型能力方面并非最专业。其二，也是最关键的问题，新负责人加入后，原有AI团队并未被完全重组，而是将其并入现有组织结构。这导致新负责人无法有效开展工作，因为原有的建制派，这反映了其在组织管理上的不成熟。相比之下，其他厂商普遍采取了“摧毁重建”的模式，比如国内阿里、字节和腾讯都吸取了相关经验。核心结论是，新负责人上任时，必须彻底重组原有团队，让其带领自己的团队，而不是让新旧团队相互汇报，这种混合结构是无法有效运作的。

同样，人才流失对OpenAI造成了很大问题，是其被快速追赶的重要因素。海外厂商如Anthropic之所以能迅速崛起，很大程度上是因为截胡了大量来自OpenAI的优质人才。在国内，DeepSeek面临模型发布困难的核心原因同样是人才被严重挖角，这背后是激励机制的问题。由于DeepSeek未上市，相比于Minimax等公司能为核心人才提供价值数亿市值的股权，其薪资和股权激励缺乏竞争力。因此，公司是否上市以及未来的上市规划，对人才稳定性有至关重要的影响。

6，在当前市场环境下，海归AI人才的流向发生了怎样的变化，大厂和小厂在人才争夺中各自处于什么位置？

当前是国内大厂吸引海归人才的有利时间点。与两年前人才倾向于加入未上市的小厂以获取原始股不同，现在小厂的格局已基本确定，要么已经上市，要么不打算上市。对于海归人才而言，此时加入已上市的小厂无法获得早期股权的高回报，而薪资待遇又不如大厂。因此，近期海外人才回国更倾向于进入大厂。同时，随着早期小厂员工的股票解禁，会出现新一轮的人才流动，大厂有机会从中招揽人才。归根结底，人才流动的核心驱动力是个人所能获得的权限、薪资和股权等综合利益的衡量。

7，针对OpenClaw带动的热潮，模型厂商和云服务商谁是主要受益者？

目前阶段，大模型商业化的主要受益者是头部的云服务商，而非模型厂商本身，尤其是小厂。大厂利用小厂（如Kimi、Minimax）的开源模型，在自己的云环境中部署并向客户销售服务，而模型厂商除了获得声誉外，并未分得实际利润。

小厂自行销售API也面临困境：首先，由于使用大厂的云资源，成本中包含了一部分需支付给云厂商的毛利，导致其token定价无法低于大厂；其次，大厂出于自身资源紧张的考虑，会限制分配给小厂的算力资源（例如限制为2万卡），这导致小厂服务的用户总数和DAU都受到底层算力的制约，发展空间受限。

8，在国内模型能力差距不大的情况下，未来模型厂商（如Kimi、Minimax）如何才能建立竞争壁垒并实现商业模式的跑通？

目前国内各家模型能力给人的感觉差距不大，主要是因为Kimi等厂商阶段性地开源了其模型。如果所有模型都是闭源的，Kimi凭借其更强的能力和产品，本可以形成明显的竞争优势。未来的破局点在于，当Kimi或Minimax的下一代模型能力实现显著提升后，它们将转向闭源。届时，大厂可能在一个版本代差内难以追赶，这将使这些模型厂商有机会凭借技术优势打造出类似Anthropic Claude那样的标杆产品，形成事实上的市场领先地位。这种“技术窗口期+产品入口壁垒”的模式，是它们独立存在并跑通商业模式的关键。当前单纯的开源模式无法盈利，除非效仿两种路径：一是像阿里在东南亚那样，通过开源模型吸引客户，最终通过销售云服务变现；二是走DeepSeek与华为合作的硬件绑定模式，通过优化模型在特定硬件（如华为芯片）上的性能，从硬件销售中分成。目前Kimi和Minimax均未采用这两种模式，因此长期来看，它们最可能效仿Anthropic的路径，在技术能力达到一定程度后，通过闭源和打造优质产品来抢占用户入口和心智。

9，为什么大型科技公司倾向于直接挖人而不是收购独立的模型创业公司？

当前大型科技公司收购创业公司的意义不大，因为核心资产是人才而非公司这个“壳”。如果收购一家公司，其核心创始人及团队很可能在交易完成后离开，再成立一家新公司，导致收购方只得到一个空壳，无法解决根本问题。因此，大厂更关心核心人才的归属，直接挖人是更直接有效的方式。只要无法获取关键人才，收购行为就无法从根本上解决其在AI领域面临的挑战。

针对国内大模型市场，预估9月份左右以Kimi、Minimax为代表的小厂可能会将其新一代模型转为闭源。市场的胜负将取决于届时大厂是否已经追赶上小厂的模型能力，以及小厂能否利用其技术领先的窗口期成功建立起产品的用户入口壁垒。这两者之间的博弈将是决定未来市场格局的关键。

10，在国内厂商纷纷推广类似OpenClaw的产品的背景下，哪些玩家在安全与合规方面更具优势？

在安全与合规方面，大厂整体上比小厂更具品牌背书和资源优势。在大厂之间，云端的安全能力（如防火墙、安全防护服务）相差不大，真正的差异化优势体现在终端设备（本机电脑）的防护能力上。由于这类产品直接安装在用户的电脑上，需要对文件、进程进行精细化管控，例如防止误删、限制其操作特定应用（如电脑版微信）等。要实现这种级别的细腻控制，需要具备类似杀毒软件或电脑管家的技术积累。在国内大厂中，只有腾讯拥有电脑管家这类业务和长期积累的团队经验，能够将AI Agent与电脑管家深度结合。其他厂商缺乏相关业务基础，若要从零开始组建团队，不仅面临人才难寻的问题，而且这类技术的研发和打磨周期非常长，远超追赶大模型本身所需的时间，早已错过了时间窗口。
