# 奇富科技（QFIN）：互金强监管下快速压降贷款利率，利润预期大幅下降后，股价拐点何时到来？

一、4Q25业绩及1Q26展望：放款量和利润take rate创2021年以来新低，压降APR较为坚决，新放款资产质量回升
信贷余额：1260亿rmb，同比-8%，环比-9%，环比连续3个季度下滑；放款量同比-22%，环比下滑16%，季度放款量创2021年以来新低。
净利润：10.7亿rmb，同比-46%，环比-29%；受到贷款利率压降和存量信贷质量走差双重压力，平均APR环比下降140bp至19.5%，以提前满足消金平均20%利率的窗口指导。
净利润年化take rate（平均余额口径）：3.3%，去年同期6.0%，前一季度4.3%；若剔除回购CB的一次性影响，经营利润口径take rate仅2.8% vs 前一季度5.1%/去年同期7.4%，除了疫情期间历史最低水平，管理层希望监管平稳后未来能保持在3%。
资产质量方面，风控收紧后新增贷款质量回升明显，4Q25新增贷款FPD30环比-18%，12月接近两年低位。1月FPD7环比12月再改善10%，同样创两年最佳；2月C-M2已确认回到2025年7-8月水平。但存量贷款短期依然有冲击，4Q25表内贷款计提拨备达12.5%（前一季度8.9%），对业绩形成拖累。
1Q26指引：Non-GAAP净利润9-9.5亿元（YoY -51%至-53%），放款量继续收缩，提升客户质量，APR未来有继续下降趋势
回购和股东回报：2025年全年累计回购US$680mn，外加分红US$200mn（$1.54 per ADS），总计达到当年净利润98%或当前市值的52%。4Q25优先折价回购CB US$460mn（以US$399mn现金），产生2.7亿rmb收益，剩余CB约US$230mn仍流通在外。2026年目前无新增股票回购计划，但管理层明确表示现有授权计划未完全用完（剩余$450mn），待监管和宏观环境企稳后将择机重启，同时表示计划保持DPS每年增加，目前股价隐含股息回报率11.5%以上。

二、互金监管梳理：最新动态与可能路径

2.1. 已明确落地的利率上限监管

助贷新规（"9号文"）综合融资成本24%上限：国家金融监管总局《关于加强商业银行互联网助贷业务管理提升金融服务质效的通知》，2025年4月发布意见稿，2025年10月1日正式执行，商业银行助贷业务综合融资成本（含增信服务费）上限24% IRR；禁止"24+12虚拟权益"等变相突破利率上限的模式；助贷平台实行银行总行白名单准入制。
消金公司平均综合利率≤20%窗口指导：地方金融监管局对辖区消金公司的窗口指导（非正式书面文件，行业调研信息），2025年10月28日前后开始传达，预计2026年3月落地执行，核心内容新增贷款综合利率不超20%，2026年3月末存量业务平均利率达标，具体执行口径因机构而异。
网络小贷公司4倍LPR利率上限：《小额贷款公司综合融资成本管理工作指引》，2025年12月19日央行与金监总局联合印发，2026年底前，超4倍LPR（12%）新发贷款余额占比须明显下降，2027年底前，全部新发贷款综合融资成本压降至4倍LPR以内，期限不超过1个月的超短期贷款上限仍为24%，但明确禁止通过反复续贷规避监管。监管目的或是希望让小贷牌照退出资金方通道，资金来源向股份制银行和主要城商行集中。
明示贷款成本：2026年3月15日印发《个人贷款业务明示综合融资成本规定》，明确贷款人开展个人贷款业务时，应当向借款人展示综合融资成本明示表，综合计算正常履约情形下借款人承担的年化综合融资成本，除此之外不再收取其他息费，自2026年8月1日起施行。

2.2. 待明确、尚未正式文件落地（来自行业调研）

消金公司综合利率从"平均≤20%"演进为"上限≤20%" ，具体时间和适用范围未定
城商行/农商行助贷规模管控，助贷/联合贷规模上限冻结于2025年12月底水平，只减不增，城商行/农商行中助贷规模较小者，今年底前清零互联网助贷业务
互联网银行部分资产综合利率≤18%，监管窗口指导从事互联网贷款的民营/互联网银行，部分资产结构提出利率≤18%的要求，市场担忧未来会扩展到其他助贷主体

2.3. 针对利率上限情景的分析推演

监管目前在压降消金和互金利率的政策方向较为明确（此前2021年就有过一轮监管压降），尤其是在整体利率走低的环境下（1年期LPR从2021年的3.85%下降到了3.0%），在此前文章已经有过分析。目前核心争议在于利率上限会划在哪，压降利率是否变成长期化监管动作，不同机构是否会区别对待。

监管整体的政策意图，通过监管各个持牌资金方主体，来挤压高利率助贷业务空间，目前基本清除了此前24%-36%的次级信贷产品，划定24%上限（2021年也是如此要求）；通过窗口指导对消金公司划定平均利率20%上限以及城商行/农商行助贷规模进一步限制倒逼减少高利率小平台的合作；对于小贷公司新发放贷款4x LPR限制，则是有意中长期清退互联网小贷作为放贷主体，和中央提出清退高风险中小金融机构的精神一致（倒逼互金平台转向助贷模式）；而目前传闻对于互联网银行18%的利率上限是否会传导到其他资金方主体，笔者觉得还不会这么快，监管秉持着不出系统性风险的前提在推进利率压降，过快一刀切会导致个人贷款供给不足，导致信贷风险蔓延到银行体系（银行信用卡贷款质量仍在恶化）。

分情景看，

1. 若利率上限仅调整到24%，平均贷款利率下调至21-22%即可，只需要放弃此前ICE高息导流业务，几家上市平台在4Q25都调整到位。但目前看来，对利率的压降要求大概率会比2021年更严格。

2. 若参照消金等资方的平均利率上限调整到20%，QFIN在4Q25已经调整到位（IRR 19.5%），FINV和LX仍偏高，在22%左右，这个情境下20-24%利率的贷款仍被允许，只是资金供给更加受限。

3. 若消金等资方的利率上限要求降到20%，那20-24%利率定价基本被禁止，次贷平台定价需要在情景1的基础上再降3-4%，平均18%的IRR定价基本宣告目前的次级客群整体UE为负，次贷平台需要新获取更好的客群来展业（即争夺借呗、微粒贷等目前14-16%左右定价的客群），难度非常大，上市平台可能仅有QFIN有机会转型。

4. 若极端情况利率上限参照互联网银行的窗口指导被限制在18%，次贷客户平台UE为负，基本无法生存，笔者认为该情景可能性较小。

从QFIN的UE看，新增贷款UE下滑较大，参考管理层3%的经营利润take rate指引，基于情景2，假设按照目前提升客户质量的策略，接下来新客平均IRR 19%，资金成本受到小贷4x LPR利率影响，或有上行压力，从现在3%以下上升至3.5%，信用成本较此前客群下降假设8%（之前9-10%），运营成本维持目前水平，占比4.5%，这样假设下经营利润take rate可以达到3%。假设接下来贷款余额在2025年基础上再下降10%，到1130亿左右，以及20%税率和一定的SBC，未来稳态的净利润在30亿rmb左右。

短期盈利不确定性在于资产质量，现有老客的资产质量受到行业流动性影响可能造成拖累，另外就是贷款规模和获客成本的平衡，公司在放弃高风险客户和主动获取更高质量的客户的过程中，4季度已经看到单位获客成本提升，贷款余额规模目前回到2024年上半年水平，2026年或继续下降。

中长期不确定性主要在1）助贷利率上限的稳态要求，2）小贷牌照利率限制对于ABS等低成本资金的影响。

但比较确定的是，每一轮行业下行周期，都是行业龙头获取市场份额的机会，QFIN在2021-22年利率压降行业低迷后（叠加疫情），在2024-25年抓住业务机会，利润绝对值已经再次回到/超过了2021年水平。

三、估值是否足够便宜，何时能看到拐点？

3.1 目前估值低于历史极值，卖方净利润预期下修较为充分

QFIN目前的PB估值低于0.5x，已经超过历史估值低点的极值（0.6x），而非限制现金及短期投资也占到市值的63%（若算上限制现金则为87%），2025年分红+回购总计payout达到98%或当前市值的52%，2025年分红比例为22%，分红payout比例有较大上升空间。管理层预计DPS会继续上升，不计算额外回购，超过$1.54 per ADS的分红，隐含dividend yield高达11.5%以上。

按照前述的计算，中性情况QFIN未来维持在19%IRR，3%经营利润take rate，小幅信贷规模下降，净利润大概在30亿rmb水平，分红比例提升到45%-50%以上即可达到目标DPS。这个情境下QFIN的ROE下降到12%左右，仍略高于招商银行ROE 11%的水平（目前估值0.8-0.9x PB）。

QFIN相较于其他上市互金公司，已经提前压降了IRR，目前部分卖方分析师对于QFIN在2026年净利润预测已经压到34亿rmb，对利率悲观看法已经较充分反映，未来下修空间相对其他更高IRR的互金公司较为有限。

3.2 接下来观测路径：监管周期拐点->资产质量周期拐点->盈利周期拐点

监管周期：已经接近底部，已经在讨论18%的利率上限，该上限为目前信用卡透支利率（日息万分之五，或年化18.25%），小贷利率新规4x LPR（12%）也已出台。
资产质量周期：头部平台由于收紧风控，提升获客质量，新放款资产质量已有改善（但获客成本增加，降低margin），而存量客户信贷风险或还会持续暴露1-2个季度（考虑到禁止24%以上利率是2025年10月，存量贷款久期在8-12个月）。
盈利周期拐点：待到利率上限明确，资产质量平稳后，头部平台放款量增速恢复增长，说明公司看到业务机会大于风险，盈利预测才有机会上修，或需要2-3个季度。

另外如果QFIN重新开始回购，将是对股价非常正面的信号，无论是从公司基本面还是fund flow的角度。

如果最后监管又重复2023-24年的情况，再次放松助贷利率上限，对QFIN会是极大利好，利润和估值会产生戴维斯双击（QFIN股价从2023年底部翻了4x左右）。

3.3 主要风险

1）监管进一步压低助贷利率上限到20%及以下，或作为长期明确的监管目标，2）额外宏观经济冲击，造成消费贷资产质量进一步恶化，3）互联网大厂金融业务客户下沉，对QFIN造成更激烈竞争，4）机构资金收紧，造成资金成本超预期上升，5）出海等新业务投入短期拖累业绩。
