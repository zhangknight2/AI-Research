# 知名投资人George Noble on OpenAI: 周期顶峰的融资景象

George Noble 是Noble Capital的CIO，也是前Fedility的PM与Peter Lynch的助理，他最新的对OpenAI的融资在X上的评论值得关注，翻译原文：

在华尔街45年的职业生涯中，我从未见过这样的事情。Sam Altman 刚刚说服了全球三位最聪明的投资者为他的亏损买单。1,100亿美元。但看不到任何盈利的迹象。这是史上最大规模的私募融资。

我来解释一下为什么这几乎接近犯罪，以及作为投资者你必须明白的几点：Amazon、Nvidia、SoftBank——全球三家最具专业水准的投资者刚刚以8,400亿美元的估值向 OpenAI 投入了1,100亿美元。这一数字是 OpenAI 去年融资400亿美元的两倍多。

作为对比：2023年全年，美国所有风险投资合计向美国初创企业投资了1,700亿美元。Altman 一轮就独自筹集了其中的65%。而且公司至今仍未实现盈利。

我们来看一下实际数据：OpenAI 在2025年烧掉了80亿美元。他们预计2026年将烧掉170亿美元，2027年为350亿美元，2028年为470亿美元。在任何可预见的盈利路径出现之前，累计亏损将超过1,150亿美元。

与此同时，**Amazon 的500亿美元投资附带了附加条件**。其中350亿美元取决于 OpenAI 是否在年底前实现 AGI 或完成 IPO。**请再读一遍。350亿美元的投资以“实现 AGI”为前提。**他们实际上是在为一项科学突破开出支票，而这项突破可能根本无法在可预测的时间内实现。**这就是周期顶峰的融资景象。**

每一位投资者都应理解的循环逻辑是：Amazon 向 OpenAI 投资500亿美元，OpenAI 承诺在 Amazon Web Services 上花费1,000亿美元。Nvidia 投资300亿美元，OpenAI 承诺购买3吉瓦的 Nvidia 算力。这些都不是独立的投资行为，而是以风险投资名义包装的**供应商融资**。Amazon 和 Nvidia 本质上是在付钱让 OpenAI 购买他们自己的产品。8,400亿美元的估值反映的是一个尚未存在的未来。

以2025年130亿美元的收入计算，市销率高达65倍。即使在2021年——近年科技史上最投机的泡沫时期——Snowflake 的市销率高点也只有50-80倍。而且 Snowflake 实际上是盈利的。J.P. Morgan 计算，AI 行业每年需要6500亿美元的收入，才能对全部基础设施建设实现10%的回报。整个行业目前的收入还只是这个数字的一小部分。在我45年的职业生涯中，我见证了无数周期。上世纪80年代的国防扩张、互联网泡沫、2008年的按揭机器。

模式始终如一：当最大的参与者开始通过循环投资结构为彼此的增长融资时，你看到的不是一场革命……你看到的是信贷周期的最后阶段。

Amazon CEO Andy Jassy 说 OpenAI 将成为“长期内最大的赢家之一”。也许吧。但8,400亿美元的估值意味着他们已经赢了。股价总是跟随盈利。过去如此，将来也如此。而现在，OpenAI 的盈利状况极度、结构性地、巨幅为负。

IPO 即将到来，市场热度将达到顶点。每一位严肃投资者都必须回答一个简单的问题：在什么价格下，这才真正合理？

Sam Altman 也不知道——他只是融资的速度比烧钱还快。

这不会有好结果。
