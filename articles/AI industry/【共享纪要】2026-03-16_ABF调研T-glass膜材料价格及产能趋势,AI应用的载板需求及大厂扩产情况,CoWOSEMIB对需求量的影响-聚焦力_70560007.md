# ABF调研:T-glass/膜材料价格及产能趋势,AI应用的载板需求及大厂扩产情况,CoWOS/EMIB对需求量的影响-聚焦力森诺科/三菱瓦斯/日东纺/味之素/台玻/南亚/宏和/臻鼎/兴森/深南等

从2025年第四季度至今，ABF载板产业链的涨价情况如何，主要驱动因素是什么？

自2025年第四季度起，由于T-glass局部缺货，其价格已调涨两次，主要影响力森诺科和三菱瓦斯。相应地，三菱瓦斯在2025年底和2026年初各涨价一次，而力森诺科于2026年3月1日宣布涨价30%。此轮涨价已传导至ABF载板和BT载板所用的CCL（覆铜板）芯材。 具体来看，产业链的涨价主要体现在以下几个方面： 首先，上游原材料，即T-glass和CCL芯材价格上涨。 其次，BT载板价格上涨。CCL芯材占BT载板成本的20%至30%，因此上游涨价直接推动BT载板价格上调。BT载板主要应用于内存模组、手机及其他移动设备的超薄基板。从2025年底BT载板涨价开始，到2026年第一季度，市场对内存的需求带动了对BT载板的抢购，封装厂在封装内存模组时需要大量BT载板，因此BT载板供应商已向封装厂或终端客户调整价格。 最后，ABF载板价格也出现上涨。由于T-glass缺货，力森诺科生产的、专供AI服务器的较厚CCL芯材也出现现货短缺。NVIDIA、AMD、博通等大客户因历史用量较大，能获得相对充足的配额。芯材和ABF原材料约占ABF载板制造成本的30%，原料价格上涨迅速反映在ABF载板的最终价格上。对于新料号的打样和试制，报价普遍较高；对于既有料号，虽未直接调价，但实行限额、限量销售给现有客户。自2026年初以来，ABF载板价格报价已逐步上调，预计到2026年第二季度及下半年，价格可能进一步上涨。

 

导致ABF载板价格持续上涨的深层原因是什么，未来价格走势和产能情况将如何演变？

ABF载板价格预计将持续上行，主要基于以下两点：其一，T-glass玻纤布的缺货问题尚未解决，导致ABF载板的出货量受到有限配额的制约。其二，专用于AI服务器的GL type ABF增层膜材料的交期正在拉长，这表明其产能已逐渐趋于紧张。若交期持续延长，可能重现2020至2021年间因产能不足导致的断料情况。 展望未来，预计到2027年下半年或2028年，高阶ABF载板可能会出现严重的产能不足和断供风险。目前尚未观察到ABF载板制造商有新的扩建计划。因此，应用于AI服务器及相关芯片的ABF载板预计将在2027年开始出现大规模缺货，其价格很可能持续上涨。

 

T-glass的供应紧张状况预计何时能得到缓解？请结合全球主要供应商的扩产计划和认证进展进行分析。

T-glass自2025年起出现约30%的供应缺口，主要由日东纺供应不足导致。为缓解此状况，各方均有相应举措：台湾供应商方面，台玻、富乔和建荣等公司自2025年下半年开始投入类T-glass产品的试制。2025年第四季度，台玻和富乔已将试产的玻纤布送样至力森诺科和三菱瓦斯制成CCL芯材，并交由载板厂进行试制。初步测试结果显示，其产品性能，如尺寸稳定性、翘曲性及电性阻抗，尚不及使用日东纺产品的原有水平，因此未能通过认证。2026年第一季度，这两家公司持续改进并再次送样，目前仍在载板厂测试中。预计2026年上半年可通过载板厂的品质认证，随后将送至OSAT厂进行上晶片测试，并交由终端客户进行最终认证。整个认证流程预计在2026年第三季度前完成。一旦通过，预计可弥补约15%的供应缺口。日东纺及其合作伙伴方面，日东纺的玻纤丝产量充足，但其自身的织布产能不足。为解决此瓶颈，2025年第四季度开始，日东纺尝试将其T-glass玻纤丝交由台湾的南亚塑胶利用其精密织布机代工织成布，再送至力森诺科和三菱瓦斯制成CCL芯材，并交由载板厂进行品质评比。此方案的认证流程预计在2026年第二季度进入上晶片电性测试及终端客户认证阶段。若上半年认证顺利通过，预计可额外弥补约5%的缺口。综合来看，到2026年底，原有的30%缺口有望恢复20%，届时仍将存在约10%的缺口。 日东纺自身的扩产计划方面，自2025年已宣布扩建，包括将旧有窑炉切换为T-glass生产线以及新建窑炉。窑炉切换需耗时半年以上，而新窑炉建设周期为一年，预计于2026年第四季度建成。之后还需进行试车、试产及产品认证，因此新窑炉预计到2027年第一季度才能正式投产。该扩产计划将使其总产能增加50%。 尽管到2027年T-glass总供应量预计将增加40%（扣除2026年底仍存的10%缺口后），但需求增长更为迅猛。AI服务器在载板厂业务中的占比将从2025年的30-40%提升至2026年的50%以上，并可能在2027年达到60-70%。此外，微软、Google、Apple、亚马逊等公司自研的ASIC芯片预计将在2026年下半年开始大规模量产，其对ABF载板的需求总量可能相当于现有NVIDIA、AMD、博通的总和。考虑到ABF载板自身也有新增产能投入，预计到2027年，T-glass在扩产后仍可能再次面临缺货。届时，中国大陆的供应商如宏和等，若能提供满足Low CTE和Low DF性能要求的类T-glass产品，可能会获得力森诺科和三菱瓦斯的测试认证机会。

 

若台湾玻璃和富乔的类T-glass产品通过验证，其月产能规模预计为多少？

目前无法获知台湾玻璃和富乔的具体月产能数据，因为它们并未公布相关信息。这些公司同时生产E-glass，类似PCB板卡的Low Dk、Low CTE玻纤布。要在现有产线中切换生产类T-glass产品，需要停炉清理，过程耗时三至六个月，成本高昂。因此，在没有新建窑炉的情况下，它们不太可能进行大规模产线切换。若现在决定投资新窑炉，建设周期约需一年，意味着新增产能最快也要到2027年底才能投产。

 

与T-glass相比，GL type ABF增层膜是否可能成为产业链中更严重的瓶颈？其主要供应商格局如何？

GL type ABF增层膜确实可能成为比T-glass更严重的瓶颈。目前，全球ABF增层膜市场由味之素高度垄断，其市场占有率超过95%，另一家供应商为日本的积水化学。中国大陆虽有公司生产旧型号的ABF膜，并已送样给海思、华为、长电等用于消费级或通用型ABF载板认证，但其产品尚未进入高阶市场，也未获得国际终端客户或OSAT厂商的认证，因此无法应用于中国以外的市场。 如果味之素生产的GL type高阶ABF膜因其产品组合调整而导致交期持续拉长，将引发重大供应危机。由于其近乎独家供应的地位，一旦产能受限且不进行扩产，市场将无替代方案，届时可能重现2020至2021年客户需携带现金赴日排队抢购货源的局面。味之素曾在2021年启动新工厂建设，并于2022年投产，但恰逢2022至2023年ABF市场需求下滑，导致其新增产能未能完全利用。

 

市场普遍认为味之素的扩产计划保守，这是否可能导致ABF在未来出现短缺？若出现短缺，预计将在何时发生，以及其背后的具体原因是什么？

是的，味之素作为一家保守的公司，其扩产决策相较于日东纺等企业更为谨慎。目前味之素并未发布新的扩产计划，仅在进行产品组合的调整，即将旧型号产线设备升级用于生产新型号产品，但新型号的具体产能尚不明确。一个值得关注的现象是，ABF膜的交期正在延长，当交期拉长到一定程度后，供给就可能中断，导致产出不足。预计这一情况将从2027年下半年开始显现，并可能在2028年演变为大规模的ABF缺货。

 

ABF膜的扩产周期通常是多久？考虑到未来可能的供应紧张，中国内地企业（如华正）的技术水平在2027年时，是否有能力供应AI服务器载板所需的ABF膜？

ABF膜的扩产周期相对较快，大约在半年到一年之间。其生产不涉及熔点高达千度的熔炉，主要设备包括树脂反应槽、填充物、改质剂、保护膜和切割机等，因此一年内可以完成扩产。然而，预计到2027年，中国内地企业仍无法供应AI服务器载板所用的ABF膜。除非其研发的新型膜在电气特性（如信号损失、信号传输速度、高频性能等）上能够满足国内AI厂商（如阿里、腾讯或达摩院等）的需求并具有参考价值，国际服务器厂商才可能考虑进行测试和认证。如果其产品仅相当于十几年前的旧型号，在电气特性、硬度和翘曲度等方面无法满足AI服务器的严苛要求，则不会被考虑。目前，这些内地企业是否正在研发可绕开味之素专利的新型膜，具体进展尚不明确，也未有相关公开信息。

 

请介绍一下当前ABF载板产业的产能分布情况，特别是台湾和中国大陆主要厂商的格局是怎样的？

讨论ABF载板的产能分布较为复杂，因为各家厂商的产品组合不同，单纯比较产能数字意义不大。产品的层数和面积对实际产出影响巨大。例如，AI服务器载板已从Hopper时代的上下各8层发展到Rubin时代的上下各12层，面积也从约6cm x 8cm或8cm x 10cm增大到10cm x 12cm。层数增加和面积增大会显著影响产量、单价、毛利率和良率。目前，AI服务器载板市场主要由日本的Ibiden、SHinko以及台湾的欣兴电子这三家主导，它们几乎包揽了英伟达和AMD的全部服务器订单。对于一般服务器载板（层数约8层，828结构，面积约6cm x 8cm），主要供应商是Ibiden、Shinko、欣兴和AT&S。AT&S已决定缩减其中国重庆工厂的规模，将一般及未来AI服务器载板的生产重心转移至其在马来西亚新建的两座工厂。重庆工厂将转向生产更低阶的产品。至于AI服务器以外的ABF载板，如用于桌面电脑、笔记本电脑、游戏机、安防设备及通用通信设备（交换机、路由器）等6层以下的产品，主要由台湾的南亚电路板和景硕，韩国的三星和LG，以及中国大陆的AT&S、南亚电路板昆山厂、欣兴电子、深南、兴森和臻鼎等厂商供应。日本的TOPPAN也参与其中。

 

在ABF载板生产中，从低层数产品转向高层数、大面积产品时，实际产能会受到怎样的影响？以一个原有1万平米月产能的工厂为例，如果从6层产品转向12层、面积更大的产品，最终有效产出会如何变化？

产能转换的计算非常复杂，会受到层数、面积、排版利用率、良率和设备兼容性等多重因素的折损。以一个拥有1万平米月产能的工厂为例，假设其生产6层以下产品的良率在80%至90%之间，有效产出约为9,000平米。当转向生产12层产品时，首先层数翻倍导致基础产能减半，即降至5,000平米。其次，由于芯片面积增大，在Panel（大板）上的排版利用率会下降，假设因此损失30%，产能将乘以0.7，剩下3,500平米。接着，良率也会因层数和复杂度的增加而下降，保守估计至少下降20%，产能再乘以0.7，剩下约2,500平米。如果部分原有设备因无法处理更大的面积或更高的层数而需要更新，在设备调试期间，稼动率会进一步降低。综合考虑，在上述2,500平米的基础上再打八折，最终有效产出可能仅为2,000平米左右。因此，理论上1万平米的低阶产品产能，在转向高阶产品后，理想状况下的有效产出大约只有2000-2,500平米。

 

ABF载板行业的产能计量单位是什么？Panel的通用尺寸是多少，以及在实际生产中，一颗芯片在Panel上的排布和利用率是怎样的？

ABF载板行业通常不使用“平米”作为产能计量单位，而是使用“Panel”的数量，例如日产1,000或2000个Panel。最终的芯片产出量需要在此基础上再乘以面积比、层数比和良率。Panel的尺寸各家载板厂不尽相同，但最通用的尺寸约为50cm x 50cm，也有45cm x 45cm或40cm x 40cm等规格，甚至510mm x 520mm的尺寸也存在。在生产中，一个Panel的排版利用率能达到80%以上已相当不错，通常落在65%至75%之间。以Hopper GPU（尺寸约6cm x 6cm，8cm x 8cm等）为例，在一个50cm x 50cm的Panel上进行排布，由于生产时需要夹边固定，四周必须预留至少5cm的边距，因此实际可利用的排版区域约为45cm x 45cm。据此计算，在45cm的边长上，可以排列7颗6cm宽的芯片；在另一边45cm的边长上，可以排列5颗8cm长的芯片。因此，一个Panel大约能产出35颗该尺寸的芯片。

 

载板生产中的Panel尺寸是否可以像面板行业一样持续增大以提升效率？CoWoS封装中，ABF载板具体承载了哪些部件？

目前载板的Panel尺寸难以像面板那样大幅增加，例如做到600mm x 600mm以上，主要限制在于基材的物理特性。与玻璃基板不同，ABF载板的有机基材存在几十个ppm的热胀冷缩系数，在尺寸增大的情况下，胀缩会导致孔位对不准，而载板的对位精度要求在10微米级别。如果强行使用更大的Panel，靠近板边的芯片良率会因对位不准或翘曲问题而大幅下降，得不偿失。在CoWoS封装流程中，GPU、CPU和HBM等芯片首先被放置在硅中介板（Silicon Interposer）上进行封装和测试。只有通过测试的、完好的硅中介板才会被贴装到ABF载板上。因此，ABF载板承载的是一个已经封装好的、大尺寸的硅中介板，而不是直接承载裸芯片或HBM。完成这一步后，整个模块会再次测试，合格后才能最终安装到PCB主板上。整个过程涉及从芯片到PCB的三次封装。

 

以Rubin为例，其ABF载板上面承载的硅中介板集成了哪些芯片？随着芯片数量和复杂度的增加，对ABF载板提出了哪些新要求？

在Rubin这类产品中，ABF载板上放置的是一颗大型硅中介板。这颗硅中介板上可能集成有两颗GPU加一颗CPU，总共三个逻辑芯片，并搭配相应的HBM。例如，一颗CPU可能搭配八颗HBM。为了容纳如此多的芯片，需要更大面积的硅中介板，这超出了传统CoWoS-S的范畴，需要CoWoS-L封装技术。相应地，承载这颗大型硅中介板的ABF载板尺寸也必须增大，例如达到10cm x 12cm。同时，由于集成的芯片数量增多，信号传输变得更复杂、速度更快，对ABF载板的层数要求也随之提高，从过去的8层左右增加到了22至24层。

 

对于下一代AI芯片，如Feynman的后续产品或谷歌TPU v8，其载板尺寸预计会达到多大？如果尺寸进一步增大，例如到15cm x 15cm，会对生产带来什么挑战？

目前下一代产品的确切尺寸尚未公布，但有传言称可能达到15cm x 15cm。如果尺寸真的达到15cm x 15cm，对生产将是巨大挑战。在一个50cm x 50cm的Panel上，考虑到留边，有效排版区域约为45cm x 45cm，每边最多只能排下3颗15cm的芯片，这意味着一个Panel最终只能产出9颗（3x3）。这将导致排版利用率极低，产能严重受限。正因为有机基板在大尺寸下面临的胀缩和翘曲问题，业界开始探索使用玻璃基板作为替代方案。玻璃基板在胀缩和翘曲控制上表现更优，但其自身也存在易碎、易裂的工艺难题。

 

如果NVIDIA的CoWoP技术路线不采用ABF载板，将会对行业产生何种影响？目前该技术路线面临哪些实际挑战？

CoWoP技术的理想状态是不使用ABF载板，但目前面临显著的技术瓶颈。PCB的制程极限约为20微米线宽，这是由于其主要采用MSAP（半加成法）而非更精密的SAP（全加成法）制程。随着晶片密度持续提升，若不通过ABF载板进行扇出，直接将硅中介层扇出到PCB上，将导致PCB尺寸急剧增大。为应对此问题，业界正在尝试在PCB中进行内埋设计，例如内埋被动元件、散热片以及高电流设计，以分担硅中介层上的部分I/O连接需求，但这增加了技术实现的难度。 更关键的挑战在于良率和成本控制。在传统流程中，若ABF载板出现品质异常，仅需报废硅中介层和载板。但若将硅中介层直接封装到PCB上，封装完成后才能进行信号损失和匹配的测试。一旦发现品质问题，将导致晶片、硅中介层和PCB整组报废，造成巨大损失。此外，大尺寸PCB固有的翘曲和胀缩问题也难以解决。综合来看，尽管CoWoP的无ABF载板构想很好，但实际整合极为困难。预计到2028年才可能看到较为具体的成果，目前仍处于概念验证和测试阶段。

 

行业内主要ABF载板厂商针对高阶AI服务器需求的扩产规划是怎样的？新旧产线的良率和产能效率有何差异？

Ibiden已连续在2024年和2025年进行扩建，并计划在2026年继续投入，其新建工厂均专注于高阶AI服务器用ABF载板，并配备了最精密、最先进的自动化设备。欣兴同样在2024、2025及2026年连续三年进行新厂扩建，目标同样是专用于AI服务器的先进自动化工厂。这两家公司新建工厂的良率改善速度领先，初期良率约为60-70%，目前量产良率已能达到80-90%。 相比之下，南亚电路板虽有能力生产AI服务器载板，但由于没有扩建新厂，其良率从50%起步，可能需要一到两年时间才能提升至80%，导致产出率较低，利润也相对较差。景硕在2026年有新工厂投入，预计2027年产出，同样定位AI服务器高端载板。若使用其旧工厂生产，由于设计多为6层以下，产能会严重受限。例如，一个设计为6层板月产1万平米的工厂，若转产12层板，月产能可能降至不足2000平米，经济效益很低。此外，臻鼎计划投入500亿建设新厂，预计2026年投资，2027年产出。韩国的三星、LG以及AT&S也有新产能投资，其中AT&S的新产能预计在2026年开出，但具体时间表尚不明确。

 

对于专注于AI领域的载板新工厂，其产能增幅相对于现有AI产能的比例大概是多少？

投入一座专为AI和5G应用设计的新工厂，大约可以为该公司增加相当于其现有AI相关产能20%-30%的产量。如果投入两座这样的新工厂，则产能增幅可达50%。

 

ABF载板厂商在向中国大陆GPU公司供货时，是否受到政策限制？ 

目前，国际知名的ABF载板厂商主要服务于国际AI客户。对于中国大陆客户，如寒武纪、海光或沐曦，这些海外载板厂的接单意愿也极低，订单量非常少，仅限于少量试制。 这些需求主要由中国大陆国内的供应链满足，包括台资厂商如群策、南电昆山厂、臻鼎、兴森，以及本土厂商如深南。由于中国大陆本土设计的芯片多采用16纳米及以上的制程，其封装密度和技术要求相对较低，不需要海外顶级的OSAT厂商（如矽品、日月光、Amkor），本土的封测厂如长电、通富、华天等即可满足其类似CoWoS技术的封装需求。相关验证测试信息非常零散，未有公开报道。

 

从历史周期看，ABF载板的价格曾出现过怎样的涨幅？当前AI相关产品与传统应用产品的价格走势有何不同？

在需求强劲的时期，ABF载板价格曾出现过翻倍的涨幅，例如在2020年和2021年产能严重短缺时。当前市场呈现分化态势，受AI需求驱动，用于AI应用的高阶ABF载板价格上涨了20%至30%。然而，用于传统消费电子领域如个人电脑、笔记本电脑和游戏机的ABF载板，由于产能并不短缺，价格基本没有上涨，仅有几个百分点的微涨。

 

AI GPU在整个ABF载板需求中的占比是多少？未来几年的趋势如何？

2025年，AI GPU在高端ABF载板厂的需求占比约为25%至35%。预计2026年，这一比例将从35%提升至50%。展望2027年，该比例可能进一步增长至60%以上。需要注意的是，这些数据主要反映拥有新建先进产能的载板厂的情况；对于没有新厂投产的一般载板厂而言，AI应用的占比会相对较低。

 

当前BT载板市场的供需状况如何？其主要应用领域的需求表现和价格走势是怎样的？

BT载板市场目前产能充足，供应来源广泛，包括中国大陆、台湾和韩国的众多厂商。其层数通常不高，多为2层或4层。BT载板的最大应用领域是memory模组，其次是手机、游戏机、可穿戴设备等便携式移动装置，再次是车用电子。 当前，由于内存市场不仅DRAM缺货，用于封装的内存模组载板也供应不足，导致内存相关BT载板价格涨势强劲。然而，用于行动装置的BT载板涨幅则温和得多，主要因为智能手机市场（尤其是Apple和中国大陆品牌）增长乏力。电动车市场表现平平，也未能带来显著需求。因此，除了内存模组应用的产线稼动率较高外，其他应用领域的BT载板产线稼动率均未满载。

 

在下游算力卡客户中，英伟达、AMD、谷歌等公司的市场份额分布如何？

从CoWoS产能分配来看，英伟达占据了约六成，AMD和博通合计占两成，剩余的两成则由谷歌、亚马逊等公司瓜分。由于一颗CoWoS芯片通常搭配一颗ABF载板，因此ABF载板厂的最大客户也是英伟达。具体到英伟达内部，其不同产品系列如Hopper、Blackwell和Rubin在各家载板供应商的份额占比各不相同，可能呈现4:6、3:7或5:5等不同比例，因此难以一概而论。

 

对于未来几年的AI芯片需求，从CoWoS产能规划和新兴技术路线来看，ABF载板的需求前景如何？

订单能见度已展望至2027年之后。CoWoS的产能正经历倍数级增长。CoWoS产能的持续释放，意味着其配套的芯片和内存订单充足，从而直接带动了对ABF载板的确定性需求。 此外，谷歌、亚马逊、苹果、特斯拉等公司为避免过度依赖CoWoS产能，正在积极测试英特尔的EMIB作为2.5D封装的替代方案。一旦EMIB技术被验证成功，且其性价比与CoWoS相当，预计到2027年将全力冲刺EMIB方案，其带来的ABF载板需求量可能是当前CoWoS需求的一倍。因此，在CoWoS和EMIB两大技术路线的共同推动下，ABF载板的产能需求将迎来爆发式增长。

 

如何评价中国大陆几家主要ABF载板厂商的技术能力？

目前来看，深南在精细度方面表现较好。臻鼎（其在深圳的礼鼎工厂）也表现不俗，能够生产10层左右的ABF载板，在产量和良率方面与深南相当，这两家可视为第一梯队。兴森快捷则属于第二梯队。
